# KubeTree v0.1.8

**Release:** v0.1.8  
**Focus:** Troubleshooting and automatic context switching

## Highlights

### Automatic context and namespace switching
- Removed the Apply button.
- Changing Kubernetes context automatically switches to the selected context.
- Changing namespace automatically loads resources from the selected namespace.
- Manual refresh remains available.

### Troubleshooting and Issues
- Improved issue visibility and grouping.
- Improved severity and issue-type labels.
- Improved handling and visibility of important workload issues, including OOMKilled and CrashLoopBackOff.
- Improved issue details and expand/collapse interactions.

### Log scanning
- Added manual log scanning for troubleshooting.
- Log scanning is bounded to avoid excessive resource consumption.
- Log matches are keyword-based indicators, not necessarily distinct incidents.

### Metrics and workload visibility
- Improved CPU and memory issue visibility.
- Improved metrics presentation and timestamps.
- Preserved the existing workload-focused experience.

## Performance and privacy
- No mandatory monitoring agent.
- No telemetry requirement.
- No background log scanning.
- Log scanning is user initiated.
- Resource-intensive operations are bounded.

## Compatibility
KubeTree continues to use the user's existing Kubernetes access and cluster configuration.
